# Masterdata Focused Context

Feature: `masterdata`

## Current Runtime

- R-12A owns exactly nine approved masterdata resources: product category, product series, product model, material category, material item, accessory category, accessory item, option set, and option value.
- Product resources display as 产品大类、产品系列、产品型号. Product model is a catalog identity, never a process/craft plan.
- Option sets are reusable value domains with `SINGLE`/`MULTIPLE`; option values require one `optionSetId`.
- R-10D changes create behavior so codes are generated by the backend, not entered by users.
- R-10F changes only product category behavior: the list is a tree table, maximum hierarchy depth is 3, edit/add cannot select self or descendants as parent, and delete is blocked while child categories exist.
- Code format is `prefix + yyyyMM + 6 digit monthly sequence`.
- Prefixes are `PC`, `PS`, `PM`, `MC`, `MI`, `AC`, `AI`, `OS`, and `OV` in the resource order above. Migrated `SOC`/`SOV` codes are retained identities only.
- The shared business generator lives at `ruoyi-business/src/main/java/com/ruoyi/business/common/code/BusinessMonthlyCodeGenerator.java`; it must not move to `ruoyi-common`.

## Boundaries

- Do not create sales-order runtime.
- Do not create field-scheme, formula, or technical-decomposition runtime.
- Do not create inventory, BOM, production, scan, drawing, shipment, finance, or receipt runtime.
- Do not modify customer runtime or idempotency runtime in masterdata code-generation work.
- Do not use product category for opening mode, color, handle, lock, hinge, glass, surface treatment, or packaging; those may be reusable option values.
- Do not add field ownership/default/validation/display metadata or process/formula/BOM/DXF behavior to option sets.
- `beforeSalesOrder` remains blocked.

## Verification Focus

- `tests/masterdata-runtime.test.js` guards the exact nine resources, OS/OV prefix mapping, option mode/ownership/delete/options behavior, old-surface absence, code format and immutability, product-category tree/depth/cycle/delete protections, frontend behavior, material/accessory regression, and forbidden runtime absence.
