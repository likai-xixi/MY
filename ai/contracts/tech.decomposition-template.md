# Technical Decomposition Contract

Status: superseded by the generic decomposition model in `engineering-core.domain.md` and `engineering-core.calculation-io.md`.

Decomposition emits nodes with `nodeKey`, `parentNodeKey`, type/role codes, quantity, keyed measurements/attributes, material snapshots, operations, geometry requests, and source trace. Main leaf, secondary leaf, grid, splice, and segment are data values, not fixed columns or dedicated order fields.
