# Technical Calculation Snapshot Contract

Status: superseded by `engineering-core.calculation-io.md` and `engineering-core.version-release.md` in R-11.

A calculation snapshot is immutable append-only evidence containing the canonical input, canonical decomposition output, diagnostics, adapter/version identity, referenced versioned artifacts, and content hashes. Recalculation creates a new snapshot. Generic CRUD cannot update or delete it.
